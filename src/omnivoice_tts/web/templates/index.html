JSON 형식이 처음이라면

⬇ 샘플 파일 받기 (ch99_script.json) — 받아서 그대로 끌어놓으면 바로 동작합니다.

꼭 필요한 건 scenes[] 안의 scene(번호)과 narration_text(읽을 문장) 둘뿐입니다.

{
  "chapter": 99,
  "scenes": [
    {
      "scene": 1,
      "narration_text": "읽을 문장입니다.",
      "srt_text": "자막에 넣을 문장 (생략하면 위와 동일)",
      "voice_style": "W1",
      "narration_seconds": 3.0
    }
  ]
}

voice_style 에는 목소리 코드(W1 …)를 바로 적거나, config/voice_map.yaml 의 이름(narrator 등)을 적습니다. 모르는 이름이면 기본 목소리로 읽고 경고를 띄웁니다.

📦 전체 zip (음성+자막) 📝 챕터 자막 (.srt)

    대본 .json을 올리면 장면 목록이 카드로 표시됩니다. 카드마다 발음 (TTS 입력)과 자막 (SRT 출력)이 나뉘어 있어 따로 고칠 수 있습니다.
    결과는 workspace/ch{NN}/audio · subtitles 에 저장됩니다. 카드별 생성/재생성 후에는 SRT 전체 생성으로 장 자막을 다시 합칩니다.
